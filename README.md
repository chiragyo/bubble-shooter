# Bubble Shooter - Ocean Glow Website

Static GitHub Pages site with:
- `index.html`
- `privacy-policy.html`
- `terms-of-use.html`
- `app-ads.txt`
- `robots.txt`
- `sitemap.xml`

Replace `YOUR-DOMAIN-HERE` in `robots.txt` and `sitemap.xml` before publishing on your real domain.
Replace the placeholder line in `app-ads.txt` with your real AdMob authorized seller entry.
